# Impeccable design context

## Design Context

### Users
Self-hosted MCP hub admins — currently Jeremy (gothmog) plus a small circle of
family/friends accounts. Used occasionally, often late-evening homelab
sessions, to wire MCP servers into claude.ai connectors, mint tokens, check
runtime health, and debug why a backend is down. The job is configuration and
diagnosis, not daily-driver work: a visit is short, purposeful, and usually
ends in copying a URL/key into another tool.

### Brand Personality
Quiet, utilitarian, trustworthy. An ops-room tool: unobtrusive, dense where it
matters, nothing decorative. It should feel like well-machined infrastructure —
the calm competence of a good CLI, with the ergonomics of a GUI. Emotional
goal: confidence that the system is under control.

### Aesthetic Direction
- **Dark only, refined.** Single dark theme (late-night admin use); invest in
  its polish rather than adding a light variant. Existing palette: bg #0f1115,
  card #181b22, fg #e6e8ed, muted #8b91a0, accent #5b8cff, border #262b35 —
  already blue-tinted neutrals; keep tinting toward the accent hue.
- **System-ui typography.** No webfonts; hierarchy comes from size/weight
  contrast, not typeface character. Monospace (`code`) is reserved for actual
  machine values (URLs, keys, namespaces), never as decoration.
- Server-rendered HTML, one stylesheet (static/style.css), strict CSP
  (script-src 'self', no inline JS). All interactivity via static/auth.js
  class/data-attribute hooks.

### Design Principles
1. **Machine values look like machine values.** Anything copyable is `code`
   with a copy button; anything decorative is not monospace.
2. **Density over chrome.** Prefer tight, aligned grids and tables to cards
   within cards; borders and containers only where they group.
3. **States are part of the design.** Hover, focus-visible, disabled, empty,
   error, and copied/confirmed states are explicit — no browser defaults left
   as the only affordance.
4. **One spacing rhythm.** 4px-based scale; vary spacing for hierarchy rather
   than padding everything equally.
5. **Quiet motion.** 150ms ease-out transitions on state changes only; respect
   prefers-reduced-motion; nothing bounces or glows.
